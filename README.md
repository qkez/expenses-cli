# Expenses CLI

Простой CLI-трекер расходов. Данные хранятся локально в CSV, никаких облаков и регистраций. Умеет добавлять траты, показывать список, считать статистику по категориям и экспортировать данные.

## Что умеет

- Добавлять траты с категорией, суммой, датой и заметкой
- Показывать список трат за период (день/неделя/месяц/год/конкретная дата)
- Статистика по категориям с процентами и ASCII-барами
- Экспорт в CSV (бэкап)
- Всё хранится в одном файле `~/.expenses.csv`

## Стек

- Python 3.10+
- Только стандартные библиотеки: `argparse`, `csv`, `datetime`, `collections`, `pathlib`
